MSCS532_Assignment1

This assignment implements the Insertion Sort algorithm in Python, sorting a list in monotonically decreasing order (largest to smallest). The task is from Chapter 2 of Introduction to Algorithms.

Files Included

- Insertion_Sort.py – Python script with the implemented algorithm.
- README.md – This file.

How It Works

The algorithm iterates through the list, and for each element, it inserts it into its correct position so that the list remains sorted in decreasing order.
